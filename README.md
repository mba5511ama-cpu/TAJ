# مطعم تاج | TAJ — الموقع + لوحة الإدارة

## محتويات المجلد
| الملف | الوظيفة |
|---|---|
| `index.html` | صفحة منيو الزبائن (الهوية الأصلية لتاج) |
| `style.css` | كل التصميم |
| `app.js` | المنيو، السلة، البحث، إرسال الطلب (واتساب + حفظه بقاعدة البيانات) |
| `admin/index.html` | لوحة الإدارة (تُفتح على `/admin`) — ملف واحد |
| `netlify.toml` | إعدادات الأمان للنشر على Netlify |
| `database/01_schema.sql` | الجداول والحماية (RLS) والدوال والتخزين — مطبّقة فعلاً على المشروع |
| `database/02_seed_current_menu.sql` | أصناف المنيو الحالية (9 تصنيفات، 68 صنفاً) — مطبّقة فعلاً |
| `database/03_create_admin_TEMPLATE.sql` | قالب لإضافة مدير جديد |

## قاعدة البيانات (Supabase)
- المشروع: `taj-restaurant` — الرقم `ppdzgsdfrptsoeuwszcu` — الرابط `https://ppdzgsdfrptsoeuwszcu.supabase.co`
- المفتاح الموجود داخل `app.js` و`admin/index.html` هو المفتاح **العام (anon)** وهو آمن في المتصفح؛ الحماية تتم بقواعد RLS داخل قاعدة البيانات.
- لا توجد أي أسرار أو كلمات مرور داخل الكود.

## النشر
1. ادخل إلى https://app.netlify.com/drop
2. اسحب مجلد `taj-restaurant` كاملاً (أو الـ ZIP بعد فك الضغط) إلى الصفحة.
3. سيظهر لك رابط الموقع. لوحة الإدارة على: `الرابط/admin/`
4. (اختياري) من إعدادات Netlify غيّر اسم الموقع أو اربط دومين خاصاً بك.
أي استضافة ثابتة أخرى تعمل أيضاً (Cloudflare Pages، Vercel، استضافتك)؛ فقط ارفع الملفات كما هي.

## كيف تستخدم لوحة الإدارة
- **الرئيسية:** الإحصائيات، المبيعات اليوم/الأسبوع/الشهر، رسم آخر 7 أيام، أكثر الأطباق طلباً.
- **المنيو:** إضافة طبق أو مشروب، تعديل، حذف، إخفاء/إظهار، متوفر/غير متوفر، السعر وسعر قبل الخصم، السعر الكبير للبيتزا، الوصف والمكونات، رفع صورة من الهاتف، علامتا «الأكثر طلباً» و«جديد».
- **التصنيفات:** إضافة/تعديل/حذف/إخفاء وترتيب بالأسهم ▲▼ (لا يُحذف تصنيف فيه أصناف).
- **العروض:** إعلانات وعروض بصورة ونص خصم وتاريخ بداية ونهاية، تفعيل/إيقاف وترتيب. تظهر أعلى المنيو تلقائياً.
- **الطلبات:** الحالات (جديد، مقبول، قيد التحضير، جاهز، مكتمل، ملغي)، تفاصيل الزبون والأصناف والمجموع والوقت، ملاحظات إدارية. تتحدث تلقائياً كل 25 ثانية وتظهر شارة بعدد الطلبات الجديدة.
- زر «🔑 كلمة المرور» لتغييرها، و«خروج».

أي تغيير يظهر للزبائن خلال ثوانٍ (المنيو يتحدث كل 45 ثانية وعند العودة للصفحة) بدون إعادة نشر.

## الأمان
- الزبون لا يستطيع إلا قراءة المنيو الظاهر وإرسال طلب عبر دالة `place_order`، التي **تعيد حساب الأسعار من قاعدة البيانات** وترفض الكميات والأحجام والأصناف غير الصالحة.
- كل صلاحيات الإدارة (إضافة/تعديل/حذف/قراءة الطلبات/رفع الصور) مقصورة على المستخدمين الموجودين بجدول `admins`.
- ننصح بتفعيل «Leaked password protection» من Supabase ← Authentication ← Providers ← Email.

## إضافة مدير آخر
1. Supabase ← Authentication ← Users ← Add user (أو استعمل `03_create_admin_TEMPLATE.sql`).
2. أضف رقمه بجدول `admins` من SQL Editor: `insert into public.admins(user_id) values ('USER-ID');`

## ملاحظات
- لا توجد صور للأطباق في المشروع الأصلي، لذلك ترفعها أنت من لوحة الإدارة وتظهر فوراً.
- الإضافات الخاصة (مثل «بدون بصل») تُكتب بحقل الملاحظات بالسلة وتصل بالواتساب وبلوحة الطلبات. المشروع الأصلي لا يحوي إضافات مدفوعة، لذا لم تُضف.
- إذا تعذر الاتصال بقاعدة البيانات يعرض الموقع المنيو الاحتياطي المضمّن، والطلب يذهب بالواتساب فقط.
